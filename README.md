# Instructions for SQL Setup
To run the application locally, the values in appsettings.json must be updated to match the user’s own SQL Server setup. The Server field should be changed to the name of the local SQL Server instance, and the Database field must match the database name on that machine. If SQL authentication is used, the User Id and Password values should be replaced with valid local credentials; alternatively, Windows Authentication can be enabled by using Trusted_Connection=True instead. These settings are specific to each user’s environment and must be configured correctly for the application to connect to the database successfully
